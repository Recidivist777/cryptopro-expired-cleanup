# cryptopro-expired-cleanup

Скрипт PowerShell для Windows, который убирает с компьютера просроченные электронные подписи:

- **сертификаты** с истёкшим сроком из хранилища Windows «Личное»;
- **контейнеры закрытых ключей КриптоПро** с просроченными сертификатами — в реестре, на диске (HDIMAGE), в папках на дисках и флешках, на токенах (Рутокен, JaCarta и др.);
- **пустые папки**, оставшиеся от удалённых контейнеров.

Перед удалением всё сохраняется в папку «Просроченные ЭП &lt;дата&gt;» на рабочем столе.

## Быстрый старт

1. Скачайте `udalit-prosrochennye-ep.ps1` и `zapusk.bat` в одну папку.
2. Вставьте флешки и токены, с которых нужно убрать старые подписи.
3. Дважды щёлкните `zapusk.bat`.
4. Проверьте списки и введите `да` для удаления.

Нужен установленный КриптоПро CSP (для работы с контейнерами). Проверено на Windows PowerShell 5.1.

## Ключи запуска

```powershell
.\udalit-prosrochennye-ep.ps1 -Containers            # только показать, ничего не удалять
.\udalit-prosrochennye-ep.ps1 -Delete -Containers    # удалить (после подтверждения)
```

| Ключ | Что делает |
|---|---|
| `-Delete` | Удалить найденное. Без него — только просмотр. |
| `-Containers` | Искать и удалять контейнеры КриптоПро и пустые папки от них. |
| `-AllUsers` | Проверять также хранилище сертификатов компьютера (нужны права администратора). |
| `-Force` | Удалять контейнер, даже если не удалось сделать его копию. |
| `-Yes` | Не спрашивать подтверждение. |

## Что скрипт не удаляет

- Контейнеры без сертификата или с нечитаемым сертификатом.
- Контейнеры, ключ которых используется действующим сертификатом.
- Контейнеры на диске и в реестре, с которых не удалось снять копию (если не указан `-Force`).
- Непустые папки, корни дисков, папки профиля пользователя, служебные папки КриптоПро, корзину.
- Пустые папки с числовыми именами на системном диске C:.

С токенов снять копию контейнера технически невозможно — такие контейнеры удаляются без копии, после общего подтверждения. КриптоПро может запросить PIN-код.

## Как работает

1. `csptest -keyset -enum_cont -fqcn` — список всех контейнеров.
2. `certmgr -export -container` — сертификат из каждого контейнера, проверка срока.
3. Копия: ветка реестра (`reg export`) или папка контейнера (поиск по `name.key`).
4. `csptest -keyset -deletekeyset` с перебором типов провайдера (ГОСТ 2012/256, 2012/512, 2001). Если КриптоПро отказывает — прямое удаление папки или ветки реестра, с которых уже снята копия.
5. Удаление пустой папки контейнера и опустевших родительских папок (не выше двух уровней).
6. Удаление просроченных сертификатов из хранилища Windows.
